# Portafolio de Inteligencia Artificial
Este es un repositorio de los proyectos en los que trabajé o en los que estoy trabajando actualmente. Se actualiza periódicamente.

## Proyectos:

#### 1. Estimación de la contaminación por residuos en el Canal Bogotá de la ciudad de Cúcuta empleando visión artificial [[Enlace al repositorio completo del proyecto](https://github.com/CrhistianZahir/Detecci-n-de-Residuos-con-IA-y-Python)]

Este proyecto se presento como tesis de pregrado para graduarme como ingeniero electrónico de la Universidad Francisco de Paula Santander, en el que obtuve el reconocimiento de tesis laureada al obtener la máxima nota 5.0/5.0. En este proyecto desarrolle un modelo computacional con la capacidad de detectar la presencia de residuos a través de imágenes, y generar un archivo csv con el número de residuos detectados y el porcentaje de ocupación de estos residuos.

#### 2. Sistema de Búsqueda y Resumen de Documentos [[Enlace al repositorio completo del proyecto](https://github.com/CrhistianZahir/Sistema-de-b-squeda-y-resumen-de-documentos-IA-langchain-Hugging-Face-FAISS-Gradio-)]

#### 3. Chatbot de Soporte Técnico Basado en Documentación 🤖 [[Enlace al repositorio completo del proyecto](https://github.com/CrhistianZahir/Chatbot-de-Soporte-T-cnico-Basado-en-Documentaci-n)]

Un chatbot de IA que responde preguntas técnicas basadas en documentación, utilizando LangChain, FAISS y Modelos de Lenguaje Grandes (LLMs). Este proyecto demuestra habilidades en procesamiento de lenguaje natural (NLP), recuperación de información y despliegue de modelos generativos.

#### 4. Pokedex n8n [[Enlace al repositorio completo del proyecto](https://github.com/CrhistianZahir/pokedex-n8n)]

Proyecto de Pokedex en n8n: Generación de imágenes y descripciones de Pokémon con IA y visualización en HTML integrando APIs y servicios en la nube.

Este proyecto es una Pokedex creada con n8n. El flujo de trabajo permite a los usuarios ingresar el nombre de un Pokémon y genera:

Una imagen del Pokémon utilizando un modelo de IA de la API Hugging Face.
Una descripción generada con el uso de la API Mistral AI.
Una página HTML que muestra la tarjeta del Pokémon con su imagen (generada con IA), nombre y descripción (generada con IA).

#### 5. NLP Generador de Texto [[Enlace al repositorio completo del proyecto](https://github.com/CrhistianZahir/NLP-Generador-de-Texto)]

El presente proyecto tiene como objetivo principal emplear una red neuronal recurrente y LSTM para la generación de texto, para llevar a cabo esta actividad se emplea como corpus el contenido del libro “El Ingenioso Hidalgo Don Quijote de la Mancha” del autor Miguel de Cervantes (De Cervantes Saavedra, 2016), en el que, el modelo desarrollado aprenderá el estilo y estructura del texto de entrada para que este tenga la capacidad de generar texto similar al escrito por el autor manteniendo la coherencia.

<img src="https://github.com/CrhistianZahir/Portafolio-de-Inteligencia-Artificial/blob/main/Imagenes_IA/generador_texto.JPG" width="600" height="250">

#### 6. NLP Clasificador de Sentimientos [[Enlace al repositorio completo del proyecto](https://github.com/CrhistianZahir/NLP-Clasificador-de-Sentimientos)]

Sistema que clasifiCA textos como positivos y negativos. Para esto se importan las librerías necesarias (nltk, stopwords, etc), se carga el dataset y se observa su composición, se continua con el procesamiento de los datos, y se realiza el análisis de sentimiento con las herramientas TextBlob y Naive Bayes.
